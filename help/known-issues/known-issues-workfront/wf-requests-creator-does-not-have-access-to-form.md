# Demandes : le créateur ou la créatrice du formulaire de demande n’a pas accès au formulaire.

>[!NOTE]
>
>* Ce problème a été résolu le 26 novembre 2025.
>* Ce problème concerne les fonctionnalités disponibles uniquement dans la planification Workfront.

Lorsqu’une personne crée un formulaire de demande dans la planification Workfront, puis tente d’y accéder, elle n’y parvient pas et le message suivant s’affiche : « Vous n’avez pas accès à ce formulaire ».

_Premier signalement le jeudi 29 octobre 2025._
